# Scope and connections

**Owns:** the retention structure of a video: which questions open and close, in what order,
and where viewers are likely to drop off.

**Does not own:**

| Need | Route to |
|---|---|
| The first line / first three seconds as a line | `hook-writer` |
| Writing the whole short-form script | `short-form-video-script` |
| Shot planning and storyboards | `scripting-and-storyboarding` |
| Delivery on camera | `talking-head-and-piece-to-camera` |
| Long-form packaging (title, thumbnail) | `youtube-long-form` |
| Reading and reporting the numbers | `analytics-and-reporting` |
| Captions and the edit | `captions-and-clipping` |

**Typical flow:** draft the script with `short-form-video-script` → run the question way on it
→ sharpen the opening with `hook-writer` → film with `talking-head-and-piece-to-camera` →
after publishing, check the drop-off timestamps (measurement: the platforms' native analytics)
against the loop map.
